# HR Analytics Dashboard - PowerBI

A comprehensive Human Resources Analytics Dashboard built with Microsoft PowerBI to visualize and analyze HR data for better decision-making.

## 📊 Project Overview

This HR Analytics Dashboard provides insights into various aspects of human resources management, including employee demographics, performance metrics, retention rates, and workforce distribution. The dashboard enables HR professionals and management to make data-driven decisions regarding workforce planning and employee engagement.

## 📁 Files Included

- **HR Analytics powerbi.pbix** - Main PowerBI dashboard file containing all visualizations and data models
- **HR Data.csv** - Raw dataset used for the dashboard analysis
- **HR ANALYTICS DASHBORD.png** - Screenshot of the dashboard visualization
- **HR Analytics powerbiPDF.pdf** - PDF export of the dashboard
- **HR_Analytics Powerbi Report(Lindah_Sumbati) (2).pdf** - Detailed PowerBI report
- **OVERVIEW OF THE DATASET.pdf** - Documentation describing the dataset structure and variables

## 🚀 Getting Started

### Prerequisites
- Microsoft PowerBI Desktop (free version available)
- Basic understanding of PowerBI interface

### How to Use

1. **Download the PowerBI File**
   - Download `HR Analytics powerbi.pbix`
   - Open it with PowerBI Desktop

2. **View the Dashboard**
   - The dashboard will load with pre-configured visualizations
   - Use slicers and filters to interact with the data
   - Explore different tabs/pages for various HR metrics

3. **Use the Dataset**
   - `HR Data.csv` contains the raw data
   - You can connect this CSV to PowerBI for custom analysis
   - Refer to `OVERVIEW OF THE DATASET.pdf` for data dictionary

## 📈 Dashboard Features

- **Employee Demographics Analysis** - Age, gender, department distribution
- **Performance Metrics** - Performance ratings, salary analysis
- **Retention Analysis** - Attrition rates, tenure distribution
- **Recruitment Insights** - Hiring trends, source effectiveness
- **Interactive Filters** - Filter by department, location, job role

## 📊 Data Visualizations

The dashboard includes various visualizations such as:
- Bar charts for categorical data
- Line charts for trends over time
- Pie/donut charts for distribution analysis
- Tables with detailed metrics
- KPI cards for key performance indicators
